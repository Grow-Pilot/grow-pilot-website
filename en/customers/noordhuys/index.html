01 · The pilot

What starts in January

Noordhuys grows tomatoes on 46.5 hectares and works with Ridder Productive. In January a pilot starts on one ten-hectare site.

In the pilot we look at what GrowPilot adds on the work floor. The start was deliberately set for January, so there is time to set it up calmly.

Once the pilot is running we will add to this page how it goes in the greenhouse and what the experiences are.
